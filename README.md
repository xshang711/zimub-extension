**zimub** 是一款专为 **Bilibili（哔哩哔哩）** 打造的现代化轻量浏览器字幕提取、管理与学习辅助扩展。  
专注于纯粹流畅的字幕体验：**精准时间轴双向同步**、**分P/合集字幕一键批量打包**、**多格式导出（默认 Markdown）**、**三档沉浸式护眼主题（浅色/暗夜/羊皮纸）** 与 **全键盘快捷操控**。

<h2 id="features">✨ 核心特性</h2>

- 📺 **B 站深度适配与时间轴实时同步**
  - **智能识别提取**：自动抓取视频官方字幕与创作者字幕，深度适配普通多 P 视频、稍后再看与 UP 主合集列表；
  - **精准定位跳转**：**单击字幕**立即跳转至对应起始时间，**双击字幕**快速跳转并切换播放/暂停；播放过程中字幕高亮自动滚动居中跟随；
  - **原生章节无缝适配**：支持 B 站自带的视频章节分段，章节标题一目了然，点击章节即可直达；
  - **无缝嵌入界面**：智能吸附在播放器右侧弹幕列表上方，界面比例自适应，不遮挡原站关键元素。

- 📦 **分P / UP主合集字幕一键批量打包下载**
  - **双重解析机制**：同时支持普通分 P 剧集（`pagelist`）与 UP 主大型系列合集（`ugc_season`）；
  - **一键全选抓取**：弹窗式批量管理，支持勾选目标分集、一键全选/反选，自由选择导出格式；
  - **无感批量打包**：自动按集数与标题命名，单键打包下载为 `.zip` 压缩包；独立弹窗防误触冒泡，后台依次处理不卡顿。

- 📑 **全能格式导出（默认推荐 Markdown）**
  - **默认 Markdown (`.md`)**：自动包含视频主标题、UP 主、发布时间、视频链接、每行时间戳与引用格式，极适合直接导入 **Notion**、**Obsidian**、**Logseq**、**语雀** 等知识库整理笔记；
  - **多格式支持**：同步支持 **SRT (`.srt`)**、**VTT (`.vtt`)**、**TXT 文本 (`.txt`)**、**原始 JSON (`.json`)**；
  - **音频快捷下载**：一键提取当前视频的原生高清音频轨（`.m4s`）。

- 🎨 **三档沉浸式无死角主题（单键即切）**
  - ☀️ **浅色白天（Light）**：清爽通透，适合日光充足的日常办公与学习；
  - 🌙 **深色暗夜（Dark）**：深度定制 `#18191C` 底板与柔雾白字，完美融入 B 站夜间播放器，深夜观看不眩光；
  - 🍃 **护眼暖光（Eye-Care / 羊皮纸色）**：仿微信读书 / Kindle 的暖麦米纸底色（`#FAF5EA`）与暖墨色文字，滤除刺眼蓝光，专为长时间听课记笔记设计；
  - **顶栏单键即切**：顶栏快捷图标轻点即在 ☀️ ➔ 🌙 ➔ 🍃 间无缝循环，自动持久化保存偏好。

- ⌨️ **极简交互与键盘快捷键**
  - **面板折叠解耦**：点击“字幕列表”文字不会误折叠面板，统一由右上角独立箭头控制展开与收起；
  - **键盘快速导航**：支持使用 `↑ / ↓ 方向键` 在字幕行之间穿梭切换焦点；
  - **单句极速复制**：按住 `Alt + 单击` 任意字幕，毫秒级复制该行纯文本到剪贴板；
  - **本地即时搜索**：毫秒级关键字检索，快速定位包含关键词的字幕句段。

<h2 id="installation">🚀 安装使用</h2>

### 方式一：加载已解压扩展程序（推荐）
1. 前往本项目的 [Releases](releases) 页面下载最新构建好的压缩包并解压（或从源代码自行构建生成 `dist` 目录）；
2. 打开 Chrome 或 Edge 浏览器，在地址栏输入 `chrome://extensions/` 打开扩展管理页面；
3. 打开右上角的 **「开发者模式」** 开关；
4. 点击左上角的 **「加载已解压的扩展程序」**；
5. 选择解压后的 `dist` 目录即可完成安装；
6. 打开任意 [哔哩哔哩视频播放页](https://www.bilibili.com/)，视频右侧播放列表上方即可看到 `zimub` 字幕面板。

<h2 id="batch-download">📥 合集与分P批量下载</h2>

1. 点击字幕面板顶栏右侧的更多操作图标 `···`；
2. 在下拉菜单中选择 **「批量下载合集字幕」**；
3. 弹窗会自动分析当前视频的分 P 列表或系列合集剧集：
   - 勾选你需要导出的分 P（支持一键全选）；
   - 选取导出格式（默认推荐 **Markdown (.md)**）；
   - 点击 **「一键打包下载 (.zip)」**，扩展将自动依次拉取所选字幕并打包下载。

<h2 id="shortcuts">⌨️ 快捷键说明</h2>

| 操作 | 功能说明 |
| :--- | :--- |
| **单击字幕** | 播放器立即跳转至该句字幕的起始播放时间点 |
| **双击字幕** | 播放器跳转至对应时间点并**切换暂停 / 播放状态** |

<h2 id="development">🛠️ 本地开发与构建</h2>

### 运行环境
- **Node.js**：`>= 18.0.0`
- **包管理器**：`pnpm`（推荐）或 `npm`

### 开发步骤
```bash
# 1. 克隆本仓库
git clone https://github.com/xshang711/zimub-extension.git
cd zimub-extension

# 2. 安装项目依赖
pnpm install

# 3. 启动本地开发热更新
pnpm run dev

# 4. 打包构建生产版本
pnpm run build
```
构建产物将输出至 `dist/` 目录，可直接在浏览器的 `chrome://extensions/` 中以「加载已解压的扩展程序」方式载入测试。

> [!TIP]
> **关于开发模式（Dev）的 CSP 避坑说明**：
> 生产打包（`pnpm run build`）会自动通过 `fix.cjs` 将 `web_accessible_resources` 的 `use_dynamic_url` 设置为 `false`，载入浏览器不会出现任何安全策略报错。  
> 若在运行 `pnpm run dev` 监听热更新时遇到 Chromium 内核的 CSP 拦截报错，可手动将 `dist/manifest.json` 中的 `use_dynamic_url` 改为 `false` 并重载扩展即可。
